Política de Privacidade

OD Drive — Plataforma de Gestão de Campanhas

Última atualização: abril de 2026

1. Dados coletados

A plataforma OD Drive coleta dados de cadastro de motoristas e gráficas participantes de campanhas publicitárias, incluindo nome, cidade, número de telefone, CPF, e-mail e informações de veículo. Esses dados são fornecidos diretamente pelos usuários ou importados de planilhas autorizadas.

2. Uso dos dados

Os dados coletados são utilizados exclusivamente para:

  • Gerenciamento de campanhas publicitárias
  • Comunicação via WhatsApp com motoristas e gráficas
  • Geração de relatórios de desempenho e quilometragem
  • Registro de evidências de instalação de adesivos

3. Compartilhamento de dados

Os dados não são vendidos ou compartilhados com terceiros, exceto com fornecedores de infraestrutura tecnológica necessários para operação da plataforma (como serviços de armazenamento em nuvem e API de mensagens).

4. Retenção de dados

Os dados são mantidos pelo período necessário à execução da campanha e por até 24 meses após seu encerramento, para fins de auditoria e comprovação.

5. Direitos do titular

Os titulares dos dados têm direito a solicitar acesso, correção ou exclusão de seus dados a qualquer momento, entrando em contato pelo e-mail: filipe_mm@hotmail.com

6. Segurança

Adotamos medidas técnicas e organizacionais adequadas para proteger os dados contra acesso não autorizado, perda ou divulgação.

7. Uso do WhatsApp Business API

A plataforma utiliza a API do WhatsApp Business (Meta) para envio de notificações e mensagens relacionadas às campanhas. As mensagens são enviadas apenas para números cadastrados e consentidos pelos participantes.

8. Exclusão de dados

Para solicitar a exclusão dos seus dados, entre em contato pelo e-mail: filipe_mm@hotmail.com. A solicitação será processada em até 15 dias úteis.

9. Contato

Dúvidas sobre esta política podem ser enviadas para: filipe_mm@hotmail.com
